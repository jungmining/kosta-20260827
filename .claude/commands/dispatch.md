description: 배정한 뒤 담당 하나에게만 맡긴다
---

과제: $ARGUMENTS

## 가드레일

- **dispatcher**는 `implementer`, `tester`, `reviewer`, `requirements-analyst` 중 정확히 하나만 정한다.
- 담당 결과가 허용된 이름 하나와 정확히 일치하지 않으면 실행을 중단하고 잘못된 배정만 보고한다.
- dispatcher가 정한 담당 에이전트 **하나만 정확히 한 번** 호출한다.
- 다른 에이전트 호출, 병렬 실행, 재배정, 보조 담당 지정, 추가 작업 지시는 하지 않는다.
- `handoff`, `pipeline`, `parallel-check`, `agents-review`를 후속으로 실행하지 않는다.
- 담당 에이전트의 결과가 부족하거나 실패해도 다른 에이전트를 호출하거나 작업을 추가하지 않고, 부족하거나 실패한 사실만 보고한다.
- 담당 에이전트에는 사용자가 입력한 과제 원문을 변경하지 않고 한 번만 전달한다.

## 실행 절차

1. **dispatcher**에게 담당을 정하게 한다.
2. dispatcher의 결과가 정확히 하나의 허용된 담당인지 확인한다.
3. 확인된 담당 **하나에게만 한 번** 과제 원문을 전달한다.
4. 결과를 그대로 보고한다. 되돌리거나 보완 작업을 지시하지 않는다.

## dispatcher 결과 형식 오류

`담당:` 값이 허용 목록과 다르거나 복수 담당·후속 단계가 포함되면 담당자를 호출하지 말고 오류 내용을 사람에게 보고한다.

이 명령은 여러 에이전트를 사용하는 `handoff`, `pipeline`, `parallel-check`, `agents-review`와 독립적이다. `/dispatch`의 후속 단계로 이 명령들을 사용하지 않는다.

테스트·리뷰·문서화가 필요해 보여도 별도 담당으로 분리하지 않는다. dispatcher가 지정한 담당의 단일 과제 범위를 벗어난 추가 지시를 하지 않는다.
