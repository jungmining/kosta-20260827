# `/handoff`: 구현·리뷰 왕복

[실행 원본](../../.claude/commands/handoff.md)

## 목적

구현 결과를 리뷰하고, 높은 심각도의 지적이 있으면 구현자에게 되돌려 수정한다.

## 실행 흐름

```text
implementer → reviewer
       ↑          │
       └── 높음 ──┘
```

1. `implementer`에게 구현을 맡긴다.
2. `reviewer`에게 리뷰를 맡긴다.
3. 심각도 `높음`이 하나라도 있으면 지적을 붙여 `implementer`에게 되돌린다.
4. 높은 심각도가 없어질 때까지 반복한다.

## 종료·보고 규칙

- 왕복은 최대 3회다.
- 세 번째 왕복 뒤에도 지적이 남으면 기준을 낮추지 않고 사람에게 전달한다.
- 매 왕복마다 `왕복 N회차`를 한 줄로 보고한다.

이 명령에는 `/dispatch`의 단일 호출 가드레일을 적용하지 않는다. 구현과 리뷰의 반복 자체가 이 명령의 목적이므로, 실행 시 [에이전트별 계약](../agents/README.md)을 함께 확인한다.
