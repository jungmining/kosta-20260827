# `requirements-analyst`

[실행 원본](../../.claude/agents/requirements-analyst.md)

## 역할과 절차

코드를 작성하지 않고 요구사항을 구조화한다.

1. `CLAUDE.md`와 관련 소스를 읽는다.
2. “누가 / 무엇을 / 왜” 형식의 사용자 스토리를 작성한다.
3. 변경할 파일과 함수를 지목한다.
4. 모호한 부분을 추측하지 않고 목록으로 남긴다.

## 도구와 출력

- 허용 도구: `Read`, `Grep`, `Glob`, `Write`
- 출력은 마크다운 한 장이며 마지막에 반드시 `모호한 것` 절을 둔다.
- `Write`는 분석 결과를 파이프라인 산출물로 기록하는 데 사용될 수 있다.
