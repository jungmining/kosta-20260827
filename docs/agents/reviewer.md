# `reviewer`

[실행 원본](../../.claude/agents/reviewer.md)

## 역할과 절차

파일을 수정하지 않고 구현 또는 지정 경로를 평가한다.

1. `CLAUDE.md`의 규약을 먼저 읽는다.
2. 대상 파일을 읽는다.
3. 규약 위반·보안·성능·유지보수성 관점으로 확인한다.
4. 지적마다 `높음`·`보통`·`낮음` 심각도와 파일·줄 번호를 붙인다.

## 도구와 권한

- 허용 도구: `Read`, `Grep`, `Glob`
- 읽기 전용이며 수정·구현·테스트 작성은 하지 않는다.

`handoff`에서는 `높음` 지적이 반복 여부를 결정하고, `agents-review`에서는 심각도와 줄 번호가 결과의 필수 기준이 된다. 고정된 전체 보고서 파일 형식은 에이전트 원본에 별도로 정의되어 있지 않다.
